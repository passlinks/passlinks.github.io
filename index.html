Passlink

— — —

Type a password and a 2FA secret; both are encrypted into the string below and parked after the # in the URL, where browsers never send it to a server. Nothing is kept here — you keep the string.

The master password is all that protects it. Anyone holding the string can guess at it offline, forever, with no rate limit and no way to revoke: if it leaks, change the password at the site itself. Make it long.

AES-256-GCM keyed by PBKDF2-SHA256 at 600k iterations, with a fresh random salt in every string, all in your browser. When sharing a link, send the master password through a different channel.
